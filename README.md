# 🏥 MediLink

MediLink is a full-stack healthcare platform that connects patients with doctors through a seamless and secure online experience. Patients can discover doctors, book appointments, and manage their healthcare interactions, while doctors can manage profiles, schedules, and appointments through a dedicated dashboard.

## ✨ Features

* Secure Authentication (Patient & Doctor)
* Doctor Search and Profiles
* Online Appointment Booking
* Ratings & Reviews
* Doctor Dashboard
* Responsive UI
* JWT-Based Authorization

## 🛠️ Tech Stack

* **Frontend:** Next.js, React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT, Bcrypt

## 🚀 Getting Started

```bash
git clone <repository-url>
cd MediLink
npm install
npm run dev
```
